## Known (cited)

- **Timeline:** Apps closed 27 Sep 2026 23:59 HKT · Master Classes 1–24 Oct · **Initial Submission 12–25 Oct** · Tech Master Class 7 Nov (Shenzhen) · **24h Development Day + pitching 14–15 Nov** (Cathay City).
- **Judging:** Feasibility centre-stage; BUs involved; creativity + real-world impact. Pitch language locked at apply; First/Final Pitch in-person only.
- **Oct flow on site:** Master Classes → share **proposal** (12–25 Oct) → standout ideas invited on-day → 24h build then pitches. Exact file checklist not extractable from public SPA HTML.
- **Prior Cathay Hack (2025):** Student champs *Kairos Takeoff Crew* — all-in-one **customer journey platform for HK Express**. Winning lane exists; AeroSync must differentiate on **disruption / IRROPS**, not generic journey.
- **HK Express IRROPS (public):** Fares/addons largely non-refundable; CoC generally **no financial compensation** for delay/cancel except where local law. Self-serve: `https://irop.hkexpress.com/.../irop/login`. Pain = opaque LCC rules + portal friction — not “no system exists.”
- **Navitaire:** No public HKE sandbox. Partner portals are gated (API key + New Skies agent creds + IP whitelist). Live Stratos / ONE Order / New Skies claims without Cathay access = false.
- **HKIA One ID / Flight Token:** Biometric token check-in → bag drop → e-Security → immigration → e-boarding already deployed. Building W3C VC/ZKP wallet from scratch is orthogonal to production Flight Token.
- **Industry foil:** Amadeus Passenger Recovery, Lufthansa OPR — production PSS products, not student MVPs.
