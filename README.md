# AeroSync

**Cathay Hackathon 2026** — track: *Low-cost Travel: Disruption Companion & Seamless Airport Journey*

Intelligent disruption companion for the Cathay / HK Express ecosystem. Turns the passenger phone into an autonomous recovery node during IRROPS so Terminal 2 desks stop becoming the bottleneck.

## Pitch spine (working)

**Problem:** LCC ops (tight turnarounds, lean staffing) break hard under irregular ops. Manual PNR/ticket rebuild + desk queues burn time, CASK, and NPS.

**Product:** AeroSync — cloud-native disruption companion integrated into the HK Express mobile journey.

Working pillars (research → build):

1. **Predict** — delay / cascade foresight into AOCC workflows  
2. **Recover** — algorithmic reaccommodation options pushed to the passenger  
3. **Retail** — ONE Order / modern PSS APIs so rebooks aren’t paper fights  
4. **Journey** — digital credentials / contactless path so validation doesn’t re-queue people  

Full research + Master Class questions live in the team pitch Doc (link in GC / keep private).
